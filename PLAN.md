# NOKAVA plan

- Category: a one-action on-chain greeting protocol for BOT Chain.
- Original product: NOKAVA, not a mirror of the reference brand or interface.
- Primary action: **Send a signal** to an EVM address.
- Layout deal: collage — five-column narrative beside a six-column live product window.
- Visual system: warm paper, deep teal ink, safety-orange action; no purple, glass or dark dashboard grid.
- Typography: Onest with JetBrains Mono for addresses and chain facts.
- Sections: hero communicator, public signal tape, protocol explanation, full-width closing action.
- Moment: iris-style section transition on the protocol statement; it reveals one complete block and is static under reduced motion.
- Wallet path: EIP-6963 discovery → legacy injected fallback → mobile MetaMask deep-link; explicit BOT Chain add/switch; account and network listeners.
- Preview path: sample records remain clearly labelled and writes stay blocked until a deployed address is configured.
